# Python Chapter 2 — Variables, Data Types, Operators & Input

This repository contains my practice programs and exercises from **Python Chapter 2**. The chapter focuses on the basic concepts needed to understand how Python stores, processes, and works with data.

## Topics Covered

### 1. Variables

* Creating variables
* Assigning values to variables
* Using variables in programs
* Updating variable values

### 2. Data Types

* `int` — Integer numbers
* `float` — Decimal numbers
* `str` — Strings/text
* `bool` — Boolean values
* `None` — Represents no value

### 3. Rules for Naming Variables

* Variable names can contain letters, numbers, and underscores.
* A variable name cannot start with a number.
* Variable names cannot contain spaces.
* Python keywords cannot be used as variable names.
* Variable names are case-sensitive.

### 4. Operators

Practice with different types of Python operators:

* Arithmetic operators: `+`, `-`, `*`, `/`, `%`, `//`, `**`
* Assignment operators: `=`, `+=`, `-=`, `*=`, `/=`
* Comparison operators: `==`, `!=`, `>`, `<`, `>=`, `<=`
* Logical operators: `and`, `or`, `not`

### 5. Type Conversion

Practice converting values from one data type to another using functions such as:

* `int()`
* `float()`
* `str()`
* `bool()`

### 6. User Input

Learn how to take input from the user using:

```python
input()
```

Also practice converting user input into the required data type.

## Learning Goal

The goal of this chapter is to build a strong foundation in Python variables, data types, operators, type conversion, and user input.
